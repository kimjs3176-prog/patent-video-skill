# 템플릿 장면 구성

모든 템플릿은 같은 콘텐츠 JSON 필드를 쓴다: name·sub·headline·chips·process·proof(stats|anatomy)·features·apps.
세로(9:16) 템플릿은 글자를 y 168~1330px 안에 두고 그 아래는 장식만 둔다(쇼츠·릴스 UI 영역).
모든 마지막 장면에 기술이전 문의처·특허번호·면책 문구가 들어간다(기술이전 형태는 넣지 않는다).

## S 시그니처 (tools/build_sig.py) 16:9 · 46~55초
파제인 영상처럼 **기술 자체가 움직이는** 템플릿. 콘텐츠의 `signature.type`이 이야기 순서를 고른다(A의 검은 무대 위).
- journey(식품·공정): 티저 → (**공정 편집**: 명세서가 기존 단계를 없앤다고 할 때만 — 빠지는 단계에 취소선, 사슬이 좁혀짐) →
  **재료 여정**(4~6단계, 단계마다 재료 그림이 변함: 침지·절단·증숙·가열·건조·로스팅·유탕·동결·발효·혼합·추출 등; 명세서 온도로 그래프, 영하도 자동 축) →
  성과 → (공정 편집이 없으면 특장점) → 활용 → 아웃트로.
- loop(장치): 티저 → **구성**(도면 위 부품에 점, 선이 목록으로) → **작동**(같은 도면 위에서 매질별 입자가 실제 경로로 흐름: 공기·물·열·가스·UV·고형물,
  활성 구역 발광, 옆에는 청구항 제어 루프 또는 단계 레일) → (**경로**: 두 번째 도면 위 이동, 있을 때만) → 특장점 → 활용 → 아웃트로.
- sequence(프라이머·진단): 티저 → **문제**(배경기술 수치) → **프라이머 설계**(실제 염기를 한 글자씩, 표적 부위가 켜짐; 다중 진단은 바이러스별 부위) →
  (**프로브** 비교, 있을 때만) → **판독**: Ct 곡선 / 반응 튜브 색 변화 / 다중 전기영동 밴드(실제 bp) 중 하나 → (프로브가 없으면 특장점) → 활용 → 아웃트로.
장면 길이는 데이터 양(단계·부품·프라이머 수)에 맞춰 정하고 전체 46~55초. 나레이션은 장면별 한 줄(`signature.narration`), 엔딩은 음악만.
새 유형은 build_sig.py에 장면 함수와 `narrative()` 분기를 추가한다(미생물·조성물·품종·SW는 아직 없음).

## 공통 후처리 (tools/postprocess.py, produce.py가 빌드마다 실행)
- **펜 드로잉**: 라인 아이콘이 경로마다 따로 멈췄다 이어지던(툭툭 끊기던) 그리기를, 아이콘 하나를 한 번의 부드러운 진행으로
  경로 실제 길이에 비례해 이어 그리도록 바꾼다(아직 안 그린 경로는 숨김). 등속 경로(점이 따라가는 선)는 그대로.
- **폰트 서브셋**: 영상에 쓰인 글자만 남겨 프로젝트당 폰트 10~37MB → 0.2~0.5MB. 캐시 `data/font_cache/`.
- 장면 배경의 색 번짐은 CSS blur 필터 없이 그라디언트만 쓴다(프레임마다 드는 비용 제거).

## 공통 시각 요소 (tools/visuals.py)
- `pick_figures`: 공보 도면에서 중복(해시)·작은 파일·극단 비율을 걸러 최대 n장(대표도 우선, 쪽 순서 고르게). anatomy 도면은 제외. 도면이 없으면 모든 템플릿이 단계 픽토그램 카드로 대체.
- `copy_figures`·`fig_boxes`·`add_transitions`: 도면 복사, 1~4장 배치, 장면 경계 오버레이(A 빛줄기·D 민트 워시·E 검정 딥·G 패널·H 아이리스·I 종이).
- `step_icon`: 공정 단계명 키워드 → 라인 아이콘(발효→cell, 건조→sun, 냉각→snow, 추출→flask …).
- `particle_text`: 한 줄 텍스트가 시드 고정 파티클 구름에서 조립(레지스트리 particle-text-dissolve 기법). **영상당 1회, 오프닝 코드네임에만** — 남발하지 않는다.
- `transitions`: 장면 경계 오버레이(tx 컴포지션). `blobs`/`grain`: 배경 색 번짐·종이 질감.
