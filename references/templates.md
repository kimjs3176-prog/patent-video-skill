## S 시그니처 (tools/build_sig.py) 16:9 · 46~55초
파제인 영상처럼 **기술 자체가 움직이는** 템플릿. 콘텐츠의 `signature.type`이 이야기 순서를 고른다(A의 검은 무대 위).
- journey(식품·공정): 티저 → (**공정 편집**: 명세서가 기존 단계를 없앤다고 할 때만 — 빠지는 단계에 취소선, 사슬이 좁혀짐) →
  **재료 여정**(4~6단계, 단계마다 재료 그림이 변함: 침지·절단·증숙·가열·건조·로스팅·유탕·동결·발효·혼합·추출·분쇄·성형·접종·살균·코팅·포장·농축·수확·압출·굽기·발아·재배·세척·탄화·해동·광 조사·초음파 등; 명세서 온도로 그래프, 영하도 자동 축;
  재료 뒤 회전 링과 받침 빛, 그래프에 온도 눈금·선 아래 채움·단계 노드가 켜지는 진행 레일·도착 링) →
  성과 → (공정 편집이 없으면 특장점) → 활용 → 아웃트로.
- loop(장치): 티저 → **구성**(도면을 읽어 들이는 빛 띠, 도면 위 부품에 점과 착지 링, 선이 목록으로) → **작동**(같은 도면 위에서 매질별 입자가 실제 경로로 흐름: 공기·물·열·가스·UV·고형물,
  활성 구역 발광, 옆에는 청구항 제어 루프(펄스가 원을 따라 돌며 그라디언트 꼬리를 남김) 또는 단계 레일) → (**경로**: 두 번째 도면 위 이동, 있을 때만) → 특장점 → 활용 → 아웃트로.
- sequence(프라이머·진단): 티저 → **문제**(배경기술 수치) → **프라이머 설계**(천천히 흐르는 이중 나선 위 표적 부위, 실제 염기를 한 글자씩, 부위가 켜짐; 다중 진단은 바이러스별 부위) →
  (**프로브** 비교, 있을 때만) → **판독**: Ct 곡선 / 반응 튜브 색 변화 / 다중 전기영동 밴드(실제 bp) 중 하나 → (프로브가 없으면 특장점) → 활용 → 아웃트로.
- formula(조성물·추출물): 티저 → **배합**(성분이 명세서 비율대로 차례로 부어져 용기의 층이 되고, 옆 목록의 비율이 카운트업) →
  **효능**(효능 지표마다 대조군 막대가 먼저, 처리군 막대가 나중에 서고 값이 나타남, 좋아지는 방향 표기) → 특장점 → 활용 → 아웃트로.
- lineage(품종·선발 균주): 티저 → **계보**(♀×♂ 교배 부모 또는 분리원 → 세대·선발 단계가 아래로 이어지며 켜지고, 끝의 신품종 이름이 빛남) →
  **형질**(형질마다 대비 품종 막대가 먼저, 신품종 막대가 나중에, 값 그대로) → 특장점 → 활용 → 아웃트로. (`tools/build_sig_types.py`)
- claim(범용 — 다른 유형이 맞지 않으면 claim, 모든 특허에 쓸 수 있음): 티저 → **청구항 구성**(오른쪽 청구항 카드에 구성요소 칩이 하나씩 쌓이고,
  칩마다 선이 그어져 도면 위 표식에 닿음 — 도면이 없으면 청구 대상의 틀 안에 구성 블록이 날아와 조립됨; 끝에 특징부 칩이 빛나며 "특징부" 표가 붙고 나머지는 물러남) →
  **청구항 지도**(독립항이 뿌리, 종속항이 가지로 자라며 인용한 항에서 갈라짐; 실시예 수치가 있으면 대조·이 기술 막대가 마지막에 섬) → 특장점 → 활용 → 아웃트로. (`tools/build_sig_types.py`)
장면 길이는 데이터 양(단계·부품·프라이머 수)에 맞춰 정하고 전체 41~55초. 나레이션은 장면별 한 줄(`signature.narration`), 엔딩은 음악만.

## 모션 원칙 (새 장면·템플릿을 만들 때)
설치된 `animation-principles`·`motion-art-direction`·`diagram-animation`·`chart-animation`·`kinetic-typography` 스킬과
HyperFrames 팀의 장면 연결 원칙, GSAP 공식 스킬을 바탕으로 정리한 규칙. S와 공통 프레임(A)에 적용돼 있다.
- **이징 어휘 하나**: 타임라인 기본 `power3.out`. 카드·글자 등장 `expo.out`, 퇴장 `power3.in`(등장의 약 75% 길이), 화면 안 이동 `power2.inOut`.
  오버슈트는 작은 표식(점·배지·부위)에만 `back.out(1.7)`. `bounce`·`elastic`은 쓰지 않는다(액체·재료가 바닥에 튀지 않는다).
- **한 박자에 주인공 하나**: 그림 → 카드 → 그래프처럼 0.12~0.3초씩 어긋나게. 같은 프레임에 모든 것이 시작하지 않게.
- **시간축은 선형**: 차트 곡선은 커서가 사이클 축을 일정 속도로 훑으며 드러난다(클립). 흐르는 매질(공기·물·가스) 입자도 `ease: "none"`.
- **선 그리기는 실제 길이로**: `pathLength="1"`은 써도 되지만 postprocess가 실제 길이로 바꾼다. 점이 따라가는 선은 선과 점을 같은 시간·같은 이징으로.
- **이동하는 표식은 도착 지점에 맞춰**: 점·물방울이 지점에 닿는 순간 그 지점이 켜지고, 닿을 때 살짝 눌렸다 펴진다.
- **숫자는 하나씩 센다**: 카운트업은 `expo.out` 0.75~1.1초, 다음 숫자와 겹치지 않게. `tabular-nums`. 강조 막대는 비교 막대보다 늦게, 더 천천히.
- **장면 연결**: 전환 0.5초 안에 끝나는 사선 와이프(빛 띠가 경계를 따라감) + 나가는 장면은 살짝 물러남. 큰 화면 전체 CSS blur 금지(느리고 흐릿).
- **제목**: 마스크 위로 올라오는 등장(`yPercent: 105 → 0`). 배경 빛은 장면 내내 천천히 이동(정지 화면 금지, 무한 반복 금지).
- **마지막 2~3초는 완성된 그림을 보여 주는 정지 구간**(그래프 전체 점등, 제품 등장). 영상 끝은 음악과 함께 0.8초 페이드아웃.
- **아이콘은 키워드에 맞을 때만**: 맞는 그림이 없으면 대표 아이콘으로 대신하지 말고 빼는 쪽을 택한다(`visuals.topic_icon`, `build_sig.problem_icon`).
- 시드 고정·유한 반복만(결정적·탐색 가능한 타임라인). 같은 요소에 fromTo를 여러 번 쓰거나, 늦게 시작하는 fromTo의 시작값(커진 링·보이는 커서)이
  그 전에 보이면 안 될 때는 `immediateRender: false`를 **두 번째(to) 객체**에 넣는다(첫 번째 객체에 넣으면 GSAP가 무시해 시작값이 처음부터 보인다).
- GSAP로 크기·위치를 움직이는 요소에는 CSS `transform`을 주지 않는다(`hyperframes check` 오류). 시작값은 fromTo로.

### A~I 공통 (특허마다 달라지는 요소)
- **도면 위 부품 표시**: 구성(anatomy) 장면에서 `proof.parts[].x/y`가 있는 부품마다 도면 부호 표식이 그 부품 위에 목록과 같은 순서로
  나타나고(링 한 번), 표식 층이 도면의 느린 확대와 함께 움직여 자리를 지킨다(`visuals.fig_markers`, A~I 모두).
- **표지 도면**: 공보 대표 도면이 있으면 A의 공개 장면(링 안 원판)과 D의 표지 카드에 그 도면이 들어간다(`visuals.cover_figure`). 없으면 대표 아이콘.
- **온도 프로파일**: 온도 단계가 2개 이상이면 A(공정 목록 아래)·D(타임라인 아래)에 단계별 범위 띠와 이어지는 선이 그려진다(`visuals.temp_profile`).
- **아이콘**: 단계·항목 그림은 키워드가 맞을 때만, 아니면 중립 표식(`flow`)·차트. 대표 아이콘(hero)은 표지·브랜드 자리에만.
- **수치 아닌 값 숨김**: 숫자가 없는 단계 값(MIX 등)은 빌드 때 지운다(`visuals.clean_steps`).
- **막대**: 비교 막대가 먼저 빠르게, 이 특허의 막대(hi)가 마지막에 더 천천히(`visuals.bar_at`). 숫자 카운트업은 `build.count_js` 하나로.
- **장면 연결**: D~I 장면은 블러 없이 0.4초 페이드로 들어오고, 덮는 전환(G 패널·H 원·D 민트·I 종이·E/F 암전)은 0.5초 안에 걷힌다.
  모든 영상은 마지막 0.85초에 음악과 함께 검은 화면으로 페이드아웃.

## 공통 시각 요소 (tools/visuals.py)
- `pick_figures`: 공보 도면에서 중복(해시)·작은 파일·극단 비율을 걸러 최대 n장(대표도 우선, 쪽 순서 고르게). anatomy 도면은 제외. 도면이 없으면 모든 템플릿이 단계 픽토그램 카드로 대체.
- `copy_figures`·`fig_boxes`·`add_transitions`: 도면 복사, 1~4장 배치, 장면 경계 오버레이(A 빛줄기·D 민트 워시·E 검정 딥·G 패널·H 아이리스·I 종이).
- `step_icon`: 공정 단계명 키워드 → 라인 아이콘(발효→cell, 건조→sun, 냉각→snow, 추출→flask …).
- `particle_text`: 한 줄 텍스트가 시드 고정 파티클 구름에서 조립(레지스트리 particle-text-dissolve 기법). **영상당 1회, 오프닝 코드네임에만** — 남발하지 않는다.
- `transitions`: 장면 경계 오버레이(tx 컴포지션). `blobs`/`grain`: 배경 색 번짐·종이 질감.
